# Changelog

Notable changes to Neon Survivor are documented here.

## [1.0.0] - Initial project build

- Added top-down player movement and mouse aiming.
- Added continuous projectile firing.
- Added enemy spawning and player-pursuit behaviour.
- Added five timed waves with increasing enemy difficulty.
- Added health, damage, pickups, and scoring.
- Added HUD, Victory, Game Over, and restart states.
