# Contributing

Thanks for taking an interest in Neon Survivor!

## Before you start

1. Fork the repository.
2. Create a focused branch:
   ```bash
   git checkout -b feature/your-feature
   ```
3. Keep changes scoped and explain the gameplay impact.

## Pull requests

Please include:
- A concise summary of the change.
- Steps to reproduce or test it.
- Screenshots or a short gameplay clip for visual changes.
- Any known limitations.

## Project conventions

- Keep the project compatible with the configured Godot 4.x version.
- Prefer clear, descriptive names.
- Avoid adding dependencies unless they are necessary.
- Do not mark roadmap features as complete until they are implemented and tested.
